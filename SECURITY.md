# Security

Do not place credentials, private task content, production data or transcripts in
issues or freshness reports. For a suspected secret disclosure or exploitable
security problem, use GitLab's confidential issue capability where available;
if that capability is unavailable, withhold sensitive detail and ask the maintainer
for a private channel. No invented security inbox is advertised.

Downloaded docs are untrusted data. The utility never runs retrieved commands or
changes instructions. Review source policies and redirects; do not host the script
as an arbitrary-URL fetch service. Local/runtime host controls remain in force.
The skill composes prompts; it cannot grant development, merge or deployment rights.
