# Bounded roadmap

v0.1: one usable prompt-authoring workflow, sources, fixture-tested maintenance,
portable distribution and honest host/evaluation status.

Next: observe ordinary ChatGPT manual/native use on a supported authenticated
surface; reduce prompt length where paired synthetic runs show excess detail;
then expand boundary/trigger evaluation only when observed failures justify it.

Later candidates need explicit scope: additional coding agents, richer rubrics,
and maintained source coverage. No SaaS, backend, model router, telemetry,
marketplace legal acceptance or production deployment is part of this release.
