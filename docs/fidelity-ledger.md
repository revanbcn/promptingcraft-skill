# Contract fidelity and native validation ledger

Scope: owner-authorized defect repair, regression/evaluation, GitLab MR and merge
after resolved blockers and required CI. No release, tag change or deployment.
Starting baseline: merged !2, commit `135a527`, 54 passing tests; v0.1.0 canonical.

## Root causes and transformations

- Performance handoff converted "No new dependencies" into acceptance that all
  dependency manifests/lockfiles must be unchanged. Dependency-set preservation
  and whole-file byte immutability are different contracts.
- Optional-accessibility handoff converted an unknown dialog into permission to
  pick a still-ambiguous target, and behavioral compatibility into mandated reuse.
  Unresolved identity/mechanism remained without user decision.
- Stale-docs handoff inferred clarity and required skipping planning from "small".
  The missing bug details contradicted the clarity assertion. Conditional provider
  advice on planning effort had become an unconditional task process rule.
- First updated 14-case run exposed an exception to unconditional API preservation
  and rejection of all repository/host instructions when only one injected source
  was untrusted. Both were repaired without changing cases or scoring assertions.

## Implementation and evidence

- Inline Superpowers execution; isolated managed worktree preserves owner checkout.
- Checker RED→GREEN for immutable literals, local authority, exact no-change and
  invalid annotations. Clean structural output remains REVIEW_REQUIRED.
- Consumer evaluations retain all original 14 cases and actual bad outputs.
  Regression assertions pin all three archived transformation classes.
- Six original new pressure cases and three executable stdlib fixtures predeclared
  before outputs. Artifact checks preserve exact active policy and reject duplicate
  keys, changed dependency/build fields and unauthorized writes.
- Collector RED→GREEN for observed successful source reads, denied tools, malformed
  artifacts, timeout traces, frozen plugin snapshots and exact unchanged echoes.
- 78 tests pass; validator and reproducible skill/plugin packaging pass.
- Two real Codex CLI invocations loaded standalone ZIP installations: live source
  retrieval plus draft/critique/final, and final-snapshot dated no-change. First
  outer-sandbox app-server startup failed; permitted elevated read-only child
  succeeded. No sandbox bypass or new credentials were used.
- Computer Use inventory exposed the ChatGPT app, but access was denied by the UI
  safety policy. Native ChatGPT test remains unavailable; no simulation is claimed.
