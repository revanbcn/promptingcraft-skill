## Source and downstream experiment

Six new original synthetic cases were predeclared: manifest-command repair with
an exact active policy, discussion-only alternatives, unresolved dialog target,
immutable ordered manifest, suitable no-change, and required authority correction.
The last two cases chose no-change for the adequate original and required revision
for the conflicting deploy instruction. Neither copied prompt text nor evaluator
expectations were tailored to model outputs.

A = original task body. B = final skill with synthetic dated context. C = the same
frozen skill with a bounded official summary externally verified on 2026-10-12.
All author/executor cells observed `claude-sonnet-5-5`, same local tools and fixtures.
Both B/C successfully read the exact matching source path/hash in all 12 final
composition cells. C consumed supplied verified evidence; its author did not fetch
live documentation, and no specific executor-model tuning is established. Guidance
is [attributed here](../../fixtures/verified-guidance.md); full provider content stays
outside Git. Retrieval metadata is [separate](guidance-fetch.json).

The initial source experiment is diagnostic: some sources were not read and
some handoffs leaked author workspace context. The next paired experiment fixed
source consumption. Final source and execution cells followed the material workflow
change. Every round's compact metrics and visible outputs remain separate; raw
traces, private workspaces and blind arm mappings are not published. Private local
paths in four diagnostic outputs and two native links are visibly redacted only;
operative clauses and failure evidence remain intact.

Why the earlier six executions all passed: two tiny, local, explicit functions
already had adequate original prompts and a low acceptance ceiling. That saturated
fixture completion; successful code was not evidence of better instruction quality.
The new tasks measure exact active bytes, decision/authority preservation,
clarification, actual verification and cost as well as code edits.

The final three tasks each ran once per A/B/C in fresh fixtures with rotated arm
order. Artifact checks run outside the executor, bind exact policy bytes to the
active top-level value, preserve dependency/build fields, and detect unauthorized
writes. Controller verification records positive test count separately from executor
commands. Blinded review judges actual proposals, target holds and assertions.
A correct clarification hold is not counted as an implemented dialog fix.
[Final blind execution audit](final-execution-audit.json) records six COMPLETE
(code/proposal) outcomes, three CORRECTLY_BLOCKED targets, zero observed task
requirement violations, and per-cell clarification/verification evidence.
